Onboarding and operations
=========================

The hands-on workflows: bringing a fresh environment and its boards from zero to
fully onboarded (Phase 0 control plane → Phase 1 per board), then the day-to-day
operations — toggling boot modes, PoE power control, reprovisioning, and the E2E
test harnesses — that you run for the life of the fleet.
