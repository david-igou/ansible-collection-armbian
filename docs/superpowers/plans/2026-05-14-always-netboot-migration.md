# Always-Netboot Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the collection from v1's stateful toggle model to a declarative always-netboot model with namespaced variables, simplified roles, and U-Boot PXE spec-compliant templates.

**Architecture:** Every onboarded board always has a pxelinux.cfg on rb5009. The `default` directive inside that file (driven by `armbian_netboot_boot_mode` inventory var) selects the boot mode. A single `boot_mode` role converges the board's state — no add/remove asymmetry. All variables use the `armbian_netboot_` prefix.

**Tech Stack:** Ansible 2.15+, community.routeros, ansible.netcommon, ansible.posix, Jinja2 templates, RouterOS network_cli

**Spec:** `docs/superpowers/specs/2026-05-14-always-netboot-migration-design.md`

- [ ] **Step 2: Create `roles/routeros_pxe_config/templates/pxelinux_cfg.j2`**

The spec-compliant template. Uses lowercase directives per U-Boot PXE spec. `nfs` label always rendered; `sd` label gated on `armbian_netboot_sd_partuuid`. Copy the full template from the spec (Section 3), filling in:

```jinja2
{# Per-host verbose wins over global. #}
{% set _verbose = (hostvars[_target_host].armbian_netboot_pxe_verbose
                   | default(armbian_netboot_pxe_verbose | default(false)))
                  | bool %}
{% set _model = hostvars[_target_host].armbian_netboot_board_model %}
{% set _board = armbian_netboot_board_configs[_model] %}
{% set _verbose_suffix = ' earlycon=' ~ _board.earlycon ~ ' loglevel=8 ignore_loglevel initcall_debug printk.devkmsg=on systemd.log_level=debug systemd.log_target=console systemd.journald.forward_to_console=1' if _verbose else '' %}
# pxelinux.cfg for {{ _target_host }} ({{ _model }})
# MAC: {{ hostvars[_target_host].armbian_netboot_board_mac }}
# Active mode: {{ hostvars[_target_host].armbian_netboot_boot_mode }}
# Generated by Ansible — do not edit manually.

default {{ hostvars[_target_host].armbian_netboot_boot_mode }}
timeout 50
prompt  0

label nfs
  menu label Armbian NFS root ({{ _target_host }})
  kernel armbian/{{ _model }}/vmlinuz
  initrd armbian/{{ _model }}/initrd.img
  fdt    armbian/{{ _model }}/board.dtb
  append root=/dev/nfs nfsroot={{ armbian_netboot_nfs_server_ip | default(armbian_netboot_server_ip) }}:{{ armbian_netboot_nfs_rootfs_path }}/{{ _target_host }},nfsvers=3,rw ip=dhcp console={{ _board.console }} rootwait rw{{ _verbose_suffix }}

{% if hostvars[_target_host].armbian_netboot_sd_partuuid is defined %}
label sd
  menu label Armbian on SD ({{ _target_host }})
  kernel armbian/{{ _model }}/vmlinuz
  initrd armbian/{{ _model }}/initrd.img
  fdt    armbian/{{ _model }}/board.dtb
  append root=PARTUUID={{ hostvars[_target_host].armbian_netboot_sd_partuuid }} rootfstype=ext4 rootwait rw console={{ _board.console }}{{ _verbose_suffix }}
{% endif %}
```

- [ ] **Step 3: Create `roles/boot_mode/tasks/main.yml`**

```yaml
---
# boot_mode role — dispatcher.
#
# Inputs validated by meta/argument_specs.yml:
#   armbian_netboot_boot_mode (required: nfs|sd)
#   armbian_netboot_router (required: inventory hostname of RouterOS router)
#   armbian_netboot_cycle_board, armbian_netboot_verify_state
#   armbian_netboot_boot_retry_attempts, etc.
#
# Flow:
#   1. Converge — render + upload pxelinux.cfg to rb5009.
#   2. (when cycle_board) PoE-cycle + retry stack.
#   3. (when verify_state) Assert rootfs matches declared mode.

- name: "boot_mode[{{ armbian_netboot_boot_mode }}] — converge pxelinux.cfg on rb5009"
  ansible.builtin.include_tasks: converge.yml

- name: "boot_mode[{{ armbian_netboot_boot_mode }}] — cycle and verify"
  when: armbian_netboot_cycle_board | bool
  block:
    - name: "boot_mode[{{ armbian_netboot_boot_mode }}] — power-cycle and wait for boot"
      ansible.builtin.include_tasks: cycle_and_wait.yml

    - name: "boot_mode[{{ armbian_netboot_boot_mode }}] — verify rootfs matches mode"
      ansible.builtin.include_tasks: verify.yml
      when: armbian_netboot_verify_state | bool
```

- [ ] **Step 5: Create `roles/boot_mode/tasks/verify.yml`**

Port from `roles/board_boot_state/tasks/verify_state.yml`. Replace the binary `pxe`/`disk` branching with mode-based assertions:

```yaml
---
- name: "boot_mode[{{ armbian_netboot_boot_mode }}] verify — gather facts"
  ansible.builtin.setup:

- name: "boot_mode[{{ armbian_netboot_boot_mode }}] verify — capture root mount"
  ansible.builtin.set_fact:
    _root_fstype: "{{ ansible_mounts | selectattr('mount', 'equalto', '/')
                                     | map(attribute='fstype') | first }}"
    _root_device: "{{ ansible_mounts | selectattr('mount', 'equalto', '/')
                                     | map(attribute='device') | first }}"

- name: "boot_mode[nfs] verify — assert NFS rootfs"
  when: armbian_netboot_boot_mode == 'nfs'
  ansible.builtin.assert:
    that:
      - _root_fstype in ['nfs', 'nfs4']
    fail_msg: >-
      boot_mode[nfs]: expected NFS rootfs but got
      {{ _root_device }} ({{ _root_fstype }}).

- name: "boot_mode[sd] verify — assert local block device rootfs"
  when: armbian_netboot_boot_mode == 'sd'
  ansible.builtin.assert:
    that:
      - _root_fstype not in ['nfs', 'nfs4']
      - _root_device is match('^/dev/')
    fail_msg: >-
      boot_mode[sd]: expected local block device rootfs but got
      {{ _root_device }} ({{ _root_fstype }}).
```

Modeled on the v1 `enable_netboot.yml` but reading `armbian_netboot_boot_mode` from inventory instead of hardcoding `boot_state: pxe`:

```yaml
---
# Converge board(s) to their inventory-declared boot mode.
#
# Reads armbian_netboot_boot_mode from each board's inventory and
# renders the matching pxelinux.cfg on rb5009. Idempotent — re-running
# when state matches is a no-op.
#
# Usage:
#   ansible-playbook playbooks/converge_boot_mode.yml --limit orange-pi-5-pro-01
#   ansible-playbook playbooks/converge_boot_mode.yml  # all boards

- name: Pre-flight — assert per-model /ip tftp rows exist on rb5009
  hosts: routeros_routers
  gather_facts: false
  tasks:
    - name: Plumbing check
      ansible.builtin.include_role:
        name: netboot_assets
        tasks_from: plumbing_check.yml
      vars:
        _check_models: >-
          {{ query('inventory_hostnames', target_hosts | default('boards'))
             | map('extract', hostvars, 'armbian_netboot_board_model')
             | list | unique }}
      run_once: true

- name: Converge boot mode
  hosts: "{{ target_hosts | default('boards') }}"
  gather_facts: false
  tasks:
    - name: Apply boot mode
      ansible.builtin.include_role:
        name: boot_mode
      vars:
        armbian_netboot_cycle_board: "{{ armbian_netboot_reboot | default(true) }}"
```
