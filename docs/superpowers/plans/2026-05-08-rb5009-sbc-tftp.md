# rb5009-Hosted SBC TFTP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move per-board pxelinux.cfg + per-model kernel/initrd/dtb from the netboot.xyz container on TrueNAS to `flash:/sbc/` on rb5009, since igou-ansible's iPXE chainload deploy now sets vlan9 `next-server=10.10.9.1` and the SBC can no longer reach the container's TFTP daemon.

**Architecture:** File presence on rb5009 is the only control surface (no DHCP option-set toggle). `routeros_dhcp` writes/removes per-board pxelinux.cfg + `/ip tftp` rows on rb5009 over `network_cli`. `netboot_assets` (renamed from `nfs_content`) extracts on TrueNAS, fetches kernel/initrd/dtb to control-node cache, then `net_put`s to rb5009 with per-file `/ip tftp` registration.

**Tech Stack:** Ansible 2.15+, `community.routeros.command`, `ansible.netcommon.net_put`, RouterOS 7.x `/ip tftp` and `/file` primitives.

**Spec:** [`docs/superpowers/specs/2026-05-08-rb5009-sbc-tftp-design.md`](../specs/2026-05-08-rb5009-sbc-tftp-design.md)

**Branch:** `feat/rb5009-sbc-tftp` (already created, spec already committed at `bc911e5`).

## Task 9: Add `roles/netboot_assets/tasks/stage_rb5009.yml` — net_put + /ip tftp registration

**Files:**
- Create: `roles/netboot_assets/tasks/stage_rb5009.yml`

This is the rb5009-side staging task. Run from a play with `hosts: routeros_routers, gather_facts: false`. Iterates over board models, creates flash directories, net_puts kernel/initrd/dtb (size-gated), registers `/ip tftp` rows.

- [ ] **Step 1: Create the file**

Use `Write` with this exact content:

```yaml
---
# Stages per-model SBC TFTP assets (kernel, initrd, dtb) on rb5009.
#
# Run from a play with hosts: routeros_routers, gather_facts: false.
# Iterates over the unique board_models in inventory; for each model,
# creates flash:/{{ sbc_tftp_flash_dir }}/armbian/<model>/, net_puts the
# three files (size-gated for idempotency), and registers a /ip tftp row
# per file.
#
# Pre-condition: roles/netboot_assets/tasks/per_board.yml has fetched
# the assets to {{ sbc_tftp_cache_dir }}/<model>/{vmlinuz,initrd.img,board.dtb}
# on the control node.
#
# Required facts (set via vars in the calling play):
#   _models: list of unique board_model strings present in inventory

- name: Resolve unique board models from inventory
  ansible.builtin.set_fact:
    _models: >-
      {{ groups['boards']
         | map('extract', hostvars, 'board_model')
         | list | unique }}

- name: Ensure top-level flash directory exists on rb5009
  community.routeros.command:
    commands:
      - >-
        :if ([/file find name="{{ sbc_tftp_flash_dir }}" type=directory] = "")
        do={/file add name="{{ sbc_tftp_flash_dir }}" type=directory}
  changed_when: false  # RouterOS scripts produce no output for these conditional ops

- name: Ensure flash:/{{ sbc_tftp_flash_dir }}/armbian directory exists
  community.routeros.command:
    commands:
      - >-
        :if ([/file find name="{{ sbc_tftp_flash_dir }}/armbian" type=directory] = "")
        do={/file add name="{{ sbc_tftp_flash_dir }}/armbian" type=directory}
  changed_when: false

- name: Ensure flash:/{{ sbc_tftp_flash_dir }}/armbian/<model> directory exists
  community.routeros.command:
    commands:
      - >-
        :if ([/file find name="{{ sbc_tftp_flash_dir }}/armbian/{{ item }}" type=directory] = "")
        do={/file add name="{{ sbc_tftp_flash_dir }}/armbian/{{ item }}" type=directory}
  changed_when: false
  loop: "{{ _models }}"

- name: Stat each local SBC TFTP asset
```
