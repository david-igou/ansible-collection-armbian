# Security policy

## Supported versions

This collection is at **0.0.x (alpha)**. Only the most recent release
receives security fixes; older alpha tags are not supported.

## Reporting a vulnerability

Please **do not** report security issues via public GitHub issues.

For vulnerabilities affecting this collection specifically, report
privately via GitHub's
[private vulnerability reporting](https://github.com/david-igou/ansible-collection-armbian/security/advisories/new)
on the repository. Include:

- A description of the issue and its impact
- Steps to reproduce (playbook, inventory excerpt, board model)
- Affected version(s) of the collection
- Your contact information for follow-up

You can expect:

- An acknowledgement within 7 days
- A fix or mitigation timeline depending on severity
- Credit in the changelog when the fix ships, unless you prefer to
  remain anonymous

For vulnerabilities in upstream Ansible itself or in dependent
collections (`ansible.posix`, `community.routeros`,
`ansible.netcommon`), follow the
[Ansible community security disclosure process](https://docs.ansible.com/ansible/latest/community/reporting_bugs_and_features.html#reporting-security-vulnerabilities).
