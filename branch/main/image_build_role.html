david_igou.armbian.image_build role – Build an Armbian image with armbian/build in Docker mode

Note

This role is part of the david_igou.armbian collection (version 0.1.0-alpha).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install david_igou.armbian.

To use it in a playbook, specify: david_igou.armbian.image_build.

Entry point main – Build an Armbian image with armbian/build in Docker mode

Synopsis

  • Runs the plan entry point, then, when image_build_needed is true, runs compile.sh, moves the produced .img.xz (and its .sha sidecar) into <image_build_output_dir>/<image_build_name>/ and writes manifest.json there.

  • Runs as the connecting user; that user must be in the docker group and own image_build_cache_dir and image_build_output_dir. Only the removal of the compile trees escalates privileges. Not check-mode safe.

  • After a successful run, removes the compile trees (unless image_build_keep_compile_trees) and any image in the output directory that the manifest does not name.

  • Sets the facts image_build_needed, image_build_inputs_hash and image_build_manifest (the manifest of the image in the output directory, newly written or existing).

Parameters

Parameter

Comments

image_build_board

string / required

Armbian board name, passed as BOARD=.

image_build_branch

string

Kernel branch, passed as BRANCH=.

Default: "current"

image_build_cache_dir

path / required

Builder directory for the per-target armbian/build checkouts, writable by the connecting user.

image_build_compile_args

dictionary

Extra KEY=value arguments for compile.sh. Part of the inputs hash.

Default: {"BUILD_DESKTOP": "no", "BUILD_MINIMAL": "yes", "COMPRESS_OUTPUTIMAGE": "sha,xz", "EXPERT": "yes", "KERNEL_CONFIGURE": "no"}

image_build_force

boolean

Build even when the manifest’s inputs hash matches and its image exists.

Choices:

  • false ← (default)

  • true

image_build_keep_compile_trees

boolean

Keep the kernel and U-Boot compile trees under the checkout’s cache/sources/ after a successful run.

They are about 20 GiB per target and only speed up a rebuild of the same kernel. Removing them needs privilege escalation, because the build container writes them as root.

Choices:

  • false ← (default)

  • true

image_build_min_free_gb

integer

Minimum free GiB at the cache directory.

Default: 50

image_build_name

string / required

Directory name for this build target, normally the board’s inventory hostname.

Keys <image_build_cache_dir>/<name>/ and <image_build_output_dir>/<name>/. Must not contain /.

image_build_output_dir

path

Directory for <name>/<image>.img.xz, its .sha sidecar and <name>/manifest.json.

Default: "{{ image_build_cache_dir }}/output"

image_build_ref

string

armbian/build git ref to check out.

Default: "v26.2.0-trunk.844"

image_build_release

string

Userspace release, passed as RELEASE=.

Default: "bookworm"

image_build_required_egress_hosts

list / elements=string

Hosts that must answer an HTTPS HEAD request before the build.

Default: ["github.com", "apt.armbian.com", "ghcr.io", "registry-1.docker.io"]

image_build_timeout

integer

Seconds compile.sh may run.

Default: 7200

image_build_userpatches

list / elements=dictionary

Files to place under the checkout’s userpatches/, each {dest, content}. dest is relative to userpatches/ and must not contain ...

Authoritative. Files under userpatches/ that are not listed are removed.

Default: []

content

string / required

File content, written verbatim.

dest

string / required

Path relative to userpatches/.

Entry point plan – Prepare the armbian/build tree and decide whether a build is needed

Synopsis

  • Checks free space, the Docker daemon and egress, checks out armbian/build at image_build_ref, writes image_build_userpatches and removes undeclared files under userpatches/, then compares the inputs hash with the existing manifest.json. Does not run compile.sh.

  • The inputs hash is the sha256 of the JSON of the board, branch, release, ref, userpatches and compile args. Sets the facts image_build_inputs_hash and image_build_needed (true when forced, when the manifest is missing or its inputs_hash differs, or when the image it names is missing).
