david_igou.armbian.pxelinux_render role – Render one board’s pxelinux.cfg to a local directory.

Note

This role is part of the david_igou.armbian collection (version 0.1.1-alpha).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install david_igou.armbian.

To use it in a playbook, specify: david_igou.armbian.pxelinux_render.

  • Entry point main – Render one board’s pxelinux.cfg to a local directory.

    • Synopsis

    • Parameters

Entry point main – Render one board’s pxelinux.cfg to a local directory.

Synopsis

  • Writes 01-<mac> with a label for every boot mode (nfs, sd, local, local_kernel and each key of pxelinux_render_extra_modes) and a default line selecting pxelinux_render_boot_mode. Never uploads; the caller moves the file to its TFTP server.

  • Usually run with delegate_to=localhost inside a play on the boards, so each board’s variables are in scope.

  • Sets the facts pxelinux_render_file (full path of the rendered file) and pxelinux_render_filename (01-<mac>).

Parameters

Parameter

Comments

pxelinux_render_board_mac

string / required

Board MAC address; the file is named 01-<mac>, lower case with dashes.

pxelinux_render_board_name

string

Board name shown in the file’s header comment. Omitted when empty.

Default: ""

pxelinux_render_boot_mode

string / required

Label selected by the default line. nfs, sd, local, local_kernel or a key of pxelinux_render_extra_modes.

local_kernel is a localboot 0 label; U-Boot’s localcmd decides what boots.

pxelinux_render_console

string / required

Kernel console= value, for example ttyS2,1500000.

pxelinux_render_earlycon

string

Kernel earlycon= value. Required when pxelinux_render_pxe_verbose is true.

Default: ""

pxelinux_render_extra_modes

dictionary

Additional labels, keyed by label name. Each value has menu_label, root, optional rootfstype (default ext4) and optional extra_append.

Default: {}

pxelinux_render_hostname

string / required

Board name used for the per-host NFS directory and the menu labels.

pxelinux_render_local_root

string

root= argument of the local label; must match the label disk_provision writes.

Default: "LABEL=armbi_root_local"

pxelinux_render_nfs_root_path

string / required

NFS export root; the board’s root is <path>/<pxelinux_render_hostname>.

pxelinux_render_nfs_server_ip

string / required

NFS server address written into nfsroot=.

pxelinux_render_nfs_version

integer

NFS protocol version written as nfsvers=.

Default: 3

pxelinux_render_output_dir

path / required

Local directory the file is written to.

pxelinux_render_pxe_verbose

boolean

Append earlycon and verbose kernel and systemd logging arguments to every kernel label.

Choices:

  • false ← (default)

  • true

pxelinux_render_sd_root

string

root= argument of the sd label.

Default: "LABEL=armbi_root"

pxelinux_render_tftp_dtb

string

TFTP path of the device tree. Empty renders no fdt line.

Default: "armbian/{{ inventory_hostname }}/board.dtb"

pxelinux_render_tftp_initrd

string

TFTP path of the initrd.

Default: "armbian/{{ inventory_hostname }}/initrd.img"

pxelinux_render_tftp_kernel

string

TFTP path of the kernel.

Default: "armbian/{{ inventory_hostname }}/vmlinuz"
