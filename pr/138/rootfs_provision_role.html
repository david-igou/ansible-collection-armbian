david_igou.armbian.rootfs_provision role – Provision a per-host NFS rootfs and TFTP boot files from an .img.xz

Note

This role is part of the david_igou.armbian collection (version 0.0.5-alpha).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install david_igou.armbian.

To use it in a playbook, specify: david_igou.armbian.rootfs_provision.

Entry point main – Provision a per-host NFS rootfs and TFTP boot files from an .img.xz

Synopsis

  • Fetches the image into a cache keyed by the source string, and unless the target’s sentinel already records the same source, image sha256 and hostname, extracts the image’s largest partition into rootfs_provision_target_dir with rsync --delete, removes /dev/ entries from its /etc/fstab, stages vmlinuz, initrd.img and optionally board.dtb into rootfs_provision_tftp_dir, resets the host identity (hostname, /etc/hosts, machine-id, SSH host keys, Armbian first-login prompt) and writes the sentinel .rootfs_provision.json in the target.

  • Runs as root on the host that exports the NFS rootfs. Needs xz, losetup, lsblk, udevadm, rsync and ssh-keygen there, and gathers the mounts fact subset itself. Refuses a target directory that is a mountpoint. Not check-mode safe. Sets no facts.

Parameters

Parameter

Comments

rootfs_provision_cache_dir

path / required

Download cache. The image is kept at <cache_dir>/<sha256 of src>/<basename of src>.

rootfs_provision_checksum

string

Passed to ansible.builtin.get_url as checksum, for example sha256:https://host/image.img.xz.sha.

When empty, the cached image is revalidated on every run (If-Modified-Since for a URL, a content compare for a path).

Default: ""

rootfs_provision_dtb

string

DTB path relative to the image’s DTB directory, for example rockchip/rk3588-rock-5b.dtb, staged as board.dtb. It is looked up under boot/dtb/, boot/dtbs/, boot/dtb-*/ and boot/dtbs/*/.

Empty stages no DTB and removes a previously staged one.

Default: ""

rootfs_provision_force

boolean

Re-extract even when the sentinel matches.

Choices:

  • false ← (default)

  • true

rootfs_provision_hostname

string / required

Hostname written into the rootfs.

rootfs_provision_mount_dir

path

Where the image’s root partition is mounted read-only during extraction.

Default: "/mnt/rootfs_provision"

rootfs_provision_src

string / required

The .img.xz to provision from, an http(s) URL or an absolute path on the host.

rootfs_provision_target_dir

path / required

Per-host NFS rootfs directory. Its contents are replaced by the image’s.

rootfs_provision_tftp_dir

path / required

Per-host directory that receives vmlinuz, initrd.img and board.dtb.
