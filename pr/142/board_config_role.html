david_igou.armbian.board_config role – Merge the hardware layers into the board_config fact.

Note

This role is part of the david_igou.armbian collection (version 0.1.1-alpha).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install david_igou.armbian.

To use it in a playbook, specify: david_igou.armbian.board_config.

Entry point build – Merge the build layers into the board_config_build fact.

Synopsis

  • Merges board_config_build_defaults, board_config_build_family, board_config_build_model and board_config_build_host, in that order, into the fact board_config_build.

  • Scalars and compile_args are combined recursively. userpatches lists are concatenated; a dest that appears twice fails the role.

  • A userpatch is {dest, content} or {dest, template}. A template entry is rendered with the ansible.builtin.template lookup in this host’s variable context and emitted as {dest, content}.

  • Also sets the fact board_config_build_enabled, true when any of the family, model or host build layers is defined.

Parameters

Parameter

Comments

board_config_build_defaults

dictionary

Lowest build layer, typically set once for all builds.

Default: {}

board_config_build_family

dictionary

SoC-family build layer. No default; defining it enables the build.

board_config_build_host

dictionary

Per-host build layer. No default; defining it enables the build.

board_config_build_model

dictionary

Board-model build layer. No default; defining it enables the build.

Entry point main – Merge the hardware layers into the board_config fact.

Synopsis

  • Recursively combines board_config_family, board_config_model and board_config_host, later layers winning, and sets the fact board_config.

  • Fails naming the missing field when armbian_board_name or console is empty. dtb and every other key are optional and passed through.

Parameters

Parameter

Comments

board_config_family

dictionary

SoC-family hardware layer, lowest precedence.

Default: {}

board_config_host

dictionary

Per-host hardware layer, highest precedence.

Default: {}

board_config_model

dictionary

Board-model hardware layer.

Default: {}

Entry point rootfs_src – Resolve the board’s rootfs image URL and checksum.

Synopsis

  • Sets the facts board_config_rootfs_src and board_config_rootfs_checksum.

  • With board_config_rootfs_src_override set, uses it and board_config_rootfs_checksum_override.

  • Otherwise fetches <board_config_assets_base_url>/images/<inventory_hostname>/manifest.json from the control node and derives the image URL from its image_filename, with checksum sha256:<image url>.sha. A missing manifest (HTTP 404) or one without image_filename fails with a remediation message.

Parameters

Parameter

Comments

board_config_assets_base_url

string

Base URL of the published images tree. Required unless board_config_rootfs_src_override is set.

board_config_rootfs_checksum_override

string

Checksum used with board_config_rootfs_src_override, in get_url checksum format.

Default: ""

board_config_rootfs_src_override

string

Explicit image URL or path. Skips the manifest lookup when non-empty.

Default: ""
