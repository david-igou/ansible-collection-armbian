david_igou.armbian.disk_provision role – Partition one block device from a declarative layout and populate it from a rootfs

Note

This role is part of the david_igou.armbian collection (version 0.1.1-alpha).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it use: ansible-galaxy collection install david_igou.armbian.

To use it in a playbook, specify: david_igou.armbian.disk_provision.

Entry point main – Partition one block device from a declarative layout and populate it from a rootfs

Synopsis

  • Validates the layout, renders one systemd-repart definition per layout entry under /run/disk_provision/<device>/repart.d/, runs systemd-repart against the device, mounts the new filesystems by label, rsyncs disk_provision_source onto them with --delete, writes an /etc/fstab on the root filesystem that references every mounted entry by LABEL=, and unmounts.

  • Without preserved partitions the partition table is rebuilt from scratch. When an entry has disk_provision_disk_binding.layout[].preserve_on_reprovision=true and its label already exists on the device, that partition keeps its data and is not mounted or copied; every other entry is deleted, re-created and reformatted (systemd-repart --factory-reset).

  • Gathers the mounts fact subset itself and refuses to wipe the disk that backs /. Needs root (tasks use become), and systemd-repart, rsync, lsblk, blkid, partprobe and blkdiscard on the host; installs the systemd-repart package when the binary is missing. One disk per call; loop the role for several disks. Always writes, so it is not idempotent.

Parameters

Parameter

Comments

disk_provision_disk_binding

dictionary / required

The device to provision and its layout.

device

path / required

Whole-disk path, for example /dev/nvme0n1. Partition paths are rejected.

fast_wipe

boolean

When nothing is preserved, discard the whole device with blkdiscard first and skip the per-partition discards of systemd-repart and mkfs.ext4.

Set false for devices whose TRIM support hangs.

Choices:

  • false

  • true ← (default)

force

boolean

Ignore disk_provision_disk_binding.layout[].preserve_on_reprovision and rebuild every partition.

Choices:

  • false ← (default)

  • true

layout

list / elements=dictionary / required

Partitions in on-disk order. Exactly one entry must mount at /.

format

string / required

Filesystem to create.

Choices:

  • "vfat"

  • "ext4"

  • "xfs"

  • "btrfs"

  • "swap"

id

string / required

Unique within the layout; names the rendered NN-<id>.conf definition.

label

string

Filesystem and partition label. Required for mounted and preserved entries.

vfat labels must be uppercase and at most 11 characters.

mount

path

Absolute mount path written to /etc/fstab. Omit for unmounted entries such as swap.

mount_opts

string

fstab options. Defaults to defaults,noatime for ext4, xfs and vfat, defaults,noatime,compress=zstd for btrfs and sw for swap.

preserve_on_reprovision

boolean

Keep this partition and its data when a partition with the same label already exists.

Choices:

  • false ← (default)

  • true

size

string / required

<number>MiB, <number>GiB or <number>TiB, or grow (at least 4G, fills the remaining space; at most one per layout).

type

string / required

GPT partition type; systemd-repart picks the architecture-specific GUID.

Choices:

  • "esp"

  • "linux"

  • "root"

  • "var"

  • "home"

  • "srv"

  • "swap"

disk_provision_installed_marker

boolean

Set INSTALLED=true in /etc/armbian-image-release on the new root, when that file exists, so armbian-resize-filesystem does not resize the partition.

Choices:

  • false

  • true ← (default)

disk_provision_mount_dir_base

path

Directory under which the new filesystems are mounted temporarily, at <base>/<device basename>.

Default: "/var/lib/armbian/disk_provision_mnt"

disk_provision_render_only

boolean

Validate the layout and render the repart definitions, then stop. Does not gather facts, touch the device or require it to exist.

Choices:

  • false ← (default)

  • true

disk_provision_reset_identity

boolean

Empty /etc/machine-id and /var/lib/dbus/machine-id on the new root. Leave false when the disk is for the same machine as the source.

Choices:

  • false ← (default)

  • true

disk_provision_source

path

Directory holding the rootfs to copy, usually / on a host booted from NFS.

Default: "/"
